
# Security incident

* Use dedicated group per incident, create them beforehand with enough time to add/validate members

* You must have an information classification level. Depending on classification, your validation process will vary
  * Rely on existing app authentication and Single Sign On
  * Request a shared information, employee number, identification word/phrase from a commonly accessible document like wiki, from a team password manager, or from an offline crisis document/cheatsheet for example
