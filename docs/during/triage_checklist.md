
Possible checklist for triage. Initial triage usually should be between 15-60 minute.
Reminder to adapt to context.

# Triage checklist

* What is the problem?
* Do you understand the alert? Can you explain it to someone else?
  * If no, review with peer or escalate.
* Is scope defined? single system, multiple, partially known...
* Is business impact defined?
* Are ticket fields and tags filled appropriately?
* Is it a security incident?
* Is it a privacy incident?
* Did you list what you have done so far and what could be done next?
  * Logs query
  * Evidence collection (local logs, forensics artefact, disk snapshot...)
* Do you need help? 
  * If yes, review with peer or escalate.
* Does it need to be escalated now? to L2, L3 or management.
* Did you review SOP? Which ones?
* Did you identify next actions?
  * RE&CT - https://github.com/atc-project/atc-react
* Did you identify some lessons learned?
  * Tuning false-positive
  * Process improvements
  * Automation opportunities
